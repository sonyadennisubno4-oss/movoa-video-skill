# Movoa Video Agent Skill

Unlimited AI video generator with sound: on paid plans the tenth take of a shot costs what the first did, and your first clip is free to make right now. This open-source Claude Code and Agent Skill connects AI coding assistants to [Movoa](https://movoa.ai/) using plain `curl` — no extra runtime required.

- [Text to video](https://movoa.ai/video/text-to-video) with synchronized sound in the same output file
- [Photo to video](https://movoa.ai/video/photo-to-video) animation from any public image URL
- Supports MiniMax H3, Seedance 2.5, Veo 3.1 Fast, and Seedance 2.0 ([AI video with audio](https://movoa.ai/video/ai-video-with-audio))

## Install

Copy [`SKILL.md`](SKILL.md) into your Claude Code skills directory (`~/.claude/skills/movoa-video/SKILL.md`), set `MOVOA_API_KEY` from [movoa.ai/settings/apikeys](https://movoa.ai/settings/apikeys), and ask Claude to create a video clip.
